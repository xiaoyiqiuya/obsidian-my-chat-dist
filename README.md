# My Chat（BRAT 安装源）

这是 **My Chat for Obsidian** 的安装产物仓库（只含构建产物，不含源码）。

## 必须配合 [BRAT](obsidian://show-plugin?id=obsidian42-brat) 安装

1. 安装并启用 **Obsidian42 - BRAT**
2. 命令面板执行「BRAT: Add a beta plugin for testing」
3. 输入 `xiaoyiqiuya/obsidian-my-chat-dist`
4. 设置 → 第三方插件 → 启用 **My Chat**

版本：见 [manifest.json](manifest.json)；`main.js` 已内嵌全部前端资源，无需额外文件。
